# 타워 뱀 개발 계획서 (초안)

뱀 게임의 몸 마디마다 공격 타워를 싣고, 몰려오는 적을 자동으로 공격하며 버티는 변형 미니 게임의 개발 계획이다.

- **상태:** 초안 (2026-11-28). "10. 확인할 결정"의 항목을 사용자가 정하면 이 문서를 고치고 개발을 시작한다.
- **바탕 게임:** 뱀 ([analysis/snake.md](../analysis/snake.md))
- **지킬 규칙:** [rules/world.md](../rules/world.md)의 "컨셉", "구조", "플레이 기록", [rules/threejs.md](../rules/threejs.md)
- **가칭:** 타워 뱀, 게임 id `tower-snake` (주소 `?game=tower-snake`), 폴더 `src/games/towerSnake/`

## 1. 사용자 요청 (2026-11-28)

1. **타워:** 뱀의 몸이 그냥 몸이 아니라, 마디(타일)마다 공격하는 타워가 있다.
2. **적:** 서바이벌 장르처럼 적이 몰려온다. 각 타워는 자기 범위 안의 적을 자동으로 공격한다.
3. **타워 모으기:** 판에 무작위로 생기는 타워를 먹어서 몸(타워)을 늘린다.
4. **피해:** 적과 머리가 부딪히면 몸이 하나씩 없어진다. 머리와 몸통이 부딪혀도 하나씩 없어진다.
5. **맵:** 지금 뱀(15 × 15)보다 크게 한다.
6. **구성:** 기존 뱀과 따로 있는 새 게임으로 만든다.

## 2. 한 판의 흐름

```
시작: 머리 + 기본 타워 2마디, 큰 판 가운데
  │  방향을 주면 나아가기 시작
  ▼
판에 타워 상자가 생김 ──먹음──▶ 꼬리에 그 타워 마디가 붙음
  │
  ▼
시간이 갈수록 판 밖에서 적 무리가 몰려옴 (파도)
  │  타워마다 범위 안의 적을 자동 공격 → 적 처치
  ▼
적·제 몸에 머리가 부딪힘 ──▶ 마디 하나(와 그 타워)가 없어짐, 잠깐 무적
  │
  ▼
머리만 남은 채로 또 부딪히면 끝 → 버틴 시간·처치 수·가장 긴 길이를 기록
```

목표는 **오래 버티기**다. 이기는 조건은 따로 두지 않는다 (확인할 결정 D6).

## 3. 규칙 상세

수치는 첫 구현의 기본값이고, 놀아 보며 "8. 단계 7"에서 맞춘다.

### 3.1 판

| 항목 | 제안 | 까닭 |
|---|---|---|
| 크기 | 41 × 41 칸 (판을 키우기로 정함, 칸 수는 단계 7에서 맞춤) | 적이 사방에서 몰려와도 피할 자리가 있게. 지금 뱀의 약 7.5배 넓이 (D1, 2026-11-28 사용자 결정) |
| 카메라 | 머리를 부드럽게 따라가는 카메라, 화면에 약 17 × 13칸이 보임 | 판 전체를 한 화면에 넣으면 마디·적이 너무 작아진다 (D1, 2026-11-28 사용자 결정) |
| 가장자리 | 울타리. 부딪히면 "3.5 피해"를 받고 오른쪽으로 저절로 꺾음 | 큰 판에서 벽에 닿자마자 끝나면 답답하다 (D3, 2026-11-28 사용자 결정) |
| 장애물 | 첫 버전에는 없음 | 적과 길찾기가 단순해진다 |
| 미니맵 | 화면 모서리에 판 전체를 점으로 (머리, 타워 상자, 적 무리) | 큰 판에서 타워 상자를 찾게. 글 없이 그림으로만 |

### 3.2 뱀의 움직임

- 지금 뱀과 같이 칸 단위로 나아간다 (방향 받기, 반대 방향 무시, 두 번까지 미리 받기).
- 빠르기는 초당 5칸으로 일정하게 둔다. 먹을수록 빨라지는 규칙은 없앤다. 길어질수록 다루기 어려워지는 것으로 충분하고, 타워가 적을 따라 공격할 시간이 필요하다.
- **제 몸에 부딪혀도 끝나지 않는다.** 머리는 몸을 지나가고, 마디 하나를 잃는다 (3.5).

### 3.3 마디와 타워

- 머리 뒤의 마디 하나가 타워 하나다. 머리는 공격하지 않는다.
- 타워는 마디와 함께 움직이며, 사거리 안의 적을 스스로 고르고 쏜다. 조작은 없다.
- 표적은 사거리 안에서 **머리에 가장 가까운 적**을 고른다 (머리를 지키는 쪽).

| 타워 | 모양 (그림) | 공격 | 사거리 (칸) | 피해 | 쿨다운 (초) | 특징 |
|---|---|---|---|---|---|---|
| 화살 | 노란 뾰족 지붕 탑 | 한 적에게 빠른 화살 | 4 | 10 | 0.5 | 기본 타워. 시작 마디 |
| 대포 | 둥근 포탑 | 떨어진 자리 둘레 1칸에 폭발 | 3.5 | 18 (범위) | 1.6 | 무리에 강함 |
| 얼음 | 하늘색 수정 | 한 적, 2초 동안 50% 느리게 | 3.5 | 4 | 0.8 | 몸을 지키는 데 좋음 |
| 번개 | 보라 코일 | 처음 적에서 가까운 적 3마리로 튐 | 3 | 8 → 튈 때마다 70% | 1.2 | 흩어진 적에 강함 |

- 같은 타워가 이웃 마디로 셋 붙으면 합쳐져 레벨이 오르는 규칙은 2차 범위로 둔다 (확인할 결정 D5).

### 3.4 타워 상자 (먹이)

- 판에 늘 3개 있다. 먹으면 그 자리에 바로 새 상자가 생긴다 (머리에서 6칸 넘게, 화면 밖일 수도 있음).
- 상자 위에 어떤 타워인지 그림이 떠 있다. 종류는 무작위 (화살 40%, 대포 20%, 얼음 20%, 번개 20%).
- 먹으면 **꼬리 끝에** 그 타워 마디가 붙는다 (지금 뱀처럼 꼬리가 한 칸 덜 빠지는 방식).
- 몸 길이는 최대 40마디. 가득 차면 상자를 먹어도 늘지 않고 가장 오래된 꼬리 마디를 새 타워로 바꾼다 (확인할 결정 D4).

### 3.5 피해와 끝

| 일 | 결과 |
|---|---|
| 적이 머리에 닿음 | 마디 하나를 잃는다. 그 적은 튕겨 나가고 피해를 받는다 (적 체력의 50%) |
| 머리가 제 몸 마디에 들어감 | 마디 하나를 잃는다. 머리는 계속 지나간다 |
| 머리가 울타리에 닿음 | 마디 하나를 잃고 오른쪽으로 저절로 꺾는다 (D3). 머리는 울타리 칸으로 들어가지 않고, 그 칸(tick)에 꺾은 쪽으로 나아간다. 모서리라서 오른쪽도 울타리면 왼쪽으로 꺾는다. 무적 동안 닿으면 마디는 잃지 않고 꺾기만 한다 |
| 적이 몸 마디(머리 아님)에 닿음 | 피해 없음. 적은 마디를 벽처럼 돌아간다 (D2-2, 2026-11-28 사용자 결정) |
| 피해를 받은 뒤 | 1초 동안 무적. 머리가 깜박인다. 그동안은 위 피해를 받지 않는다 |
| 머리만 남았을 때 피해 | 판이 끝난다 |

- **잃는 마디는 꼬리 끝 마디**로 한다 (D2, 2026-11-28 사용자 결정). 적·제 몸·울타리 어느 피해든 같다. 앞쪽 타워 배치는 그대로 남는다. 마디가 터지며 그 타워 조각이 흩어지는 연출을 넣는다.

### 3.6 적

- 적은 칸에 묶이지 않고 판 위를 자유롭게 움직인다 (실수 좌표). 머리 쪽으로 다가온다.
- 화면 바로 밖(머리에서 10~12칸 둘레)에서 무리로 생긴다. 판 밖에서는 생기지 않는다.
- 적끼리는 살짝 밀어내 한 점에 겹치지 않게 한다.

| 적 | 모양 | 체력 | 빠르기 (칸/초) | 나오는 때 |
|---|---|---|---|---|
| 젤리 | 작고 둥근 방울 | 20 | 2.0 | 처음부터 |
| 날쌘이 | 길쭉한 방울 | 12 | 3.6 | 1분부터 |
| 바위 | 각진 덩어리 | 90 | 1.3 | 2분부터 |
| 큰 녀석 (보스) | 큰 젤리, 맞으면 작은 젤리 4마리로 갈라짐 | 600 | 1.0 | 3분마다 하나 |

- **파도:** 2초마다 무리가 나온다. 한 무리의 수 = 3 + 지난 분 × 2 (최대 동시 적 250마리).
- 적의 빠르기는 뱀(5칸/초)보다 늘 느리다. 피할 수 있어야 한다.

### 3.7 점수와 기록

- 화면 위 점수 표 (그림 아이콘 + 숫자): 버틴 시간(모래시계), 처치 수(터진 방울), 지금 길이(마디).
- 왕관: 가장 오래 버틴 시간.
- 공용 기록장(`lib/save/`)에 `tower-snake`로 남긴다.

| 기록 | 내용 |
|---|---|
| 누적 수치 | 판 수, 가장 오래 버틴 시간, 가장 많은 처치, 가장 긴 길이, 처치 합, 논 시간 합, 타워별로 먹은 수 합 |
| 판 기록 | 버틴 시간, 처치 수, 가장 긴 길이, 먹은 타워 수(종류별), 끝난 방식(`down`·`restart`), 마지막 몸의 타워 목록 |
| 하다 만 판 | 없음 (지금 뱀과 같이 실시간 놀이) |

## 4. 화면과 조작

- **조작:** 지금 뱀과 같다. 화살표 키·WASD, 끌어서 꺾기, Space·P·Esc 멈추기, 다른 탭으로 가면 멈춤.
- **글 없음:** 버튼, 점수 표, 시작 안내, 멈춤 표시는 그림이다. 끝나면 오림 글자 `GAME OVER`. 타워 종류도 글 대신 모양과 색으로 구분한다 ([rules/world.md](../rules/world.md)의 "컨셉").
- **보이는 것:** 지금 뱀의 3D 스타일(툰 음영, 선 테두리, 파스텔 판)을 잇는다. 마디는 납작한 받침 위에 작은 탑이 선 모양. 사거리는 평소엔 보이지 않고, 적이 가까워지면 바닥에 흐린 원으로 보인다.
- **공격 연출:** 화살·포탄은 날아가는 작은 물체, 번개는 꺾인 선, 얼음은 맞은 적이 하늘색으로 바뀜. 맞은 적은 하얗게 번쩍이고, 처치되면 색종이처럼 터진다.
- **피해 연출:** 화면이 살짝 흔들리고, 잃은 마디가 튀어 오르며 부서진다.

## 5. 코드 구조

[rules/world.md](../rules/world.md)의 "구조"를 따른다: 게임은 `src/games/towerSnake/`, 다른 게임을 가져오지 않고, three.js는 `graphics/`에서만 쓴다.

### 5.1 뱀과 함께 쓸 부분

게임끼리는 서로 가져올 수 없다 (`src/layers.test.ts`가 검사). 그래서 두 게임이 함께 쓸 것은 `src/lib/`로 옮긴다.

| 옮길 것 | 옮길 곳 | 내용 |
|---|---|---|
| 칸 위의 몸 움직임 | `lib/gridSnake/` | 방향 받기, 한 칸 나아가기, 늘이기, 마디 잃기. 벽·제 몸 부딪힘은 판정만 돌려주고 결과(끝/피해)는 게임이 정한다 |
| 칸 사이 매끄럽게 잇기 | 각 게임의 `graphics/`에 둠 | 두 게임의 마디 모양이 달라 옮기지 않는다 |
| 버튼·점수 표 DOM과 CSS | 각 게임에 둠 | 아이콘과 배치가 다르다. 셋째 게임이 같은 것을 쓰게 되면 그때 `lib/`로 옮긴다 |

옮긴 뒤 지금 뱀의 테스트가 그대로 통과해야 한다.

### 5.2 파일

| 파일 | 내용 | DOM·GPU |
|---|---|---|
| `world.ts` | 한 판의 상태와 `step(dt)`. 뱀·타워·적·투사체를 고정 간격(1/60초)으로 나아가게 한다 | 없음 |
| `towers.ts` | 타워 종류 표(`TOWER_TYPES`), 표적 고르기, 쿨다운, 공격 만들기 | 없음 |
| `enemies.ts` | 적 종류 표, 움직임(머리 쪽, 몸 돌아가기, 서로 밀기), 느려짐 | 없음 |
| `waves.ts` | 시간에 따른 무리 크기·종류, 생기는 자리 | 없음 |
| `combat.ts` | 투사체, 범위 피해, 번개 튀기, 처치 | 없음 |
| `spatialGrid.ts` | 적을 칸별로 나눠 두는 격자. 사거리·충돌 찾기를 빠르게 | 없음 |
| `random.ts` | 씨앗을 받는 난수 (테스트에서 같은 판을 다시 만들기) | 없음 |
| `records.ts` | 기록 모양과 `RecordSpec` | 없음 |
| `index.ts` | `towerSnakeGame`, 입력, 단계, 고리, 점수 표, 미니맵, 개발용 `window.__towerSnake` | DOM |
| `graphics/view.ts` | 판·마디·타워·적·투사체·연출 그리기, 따라가는 카메라 | GPU |
| `shaders/` | 툰·테두리(뱀 것을 바탕으로), 사거리 원 | GPU |
| `towerSnake.test.ts` | 아래 "9. 테스트" | |

### 5.3 시간

- 뱀은 칸 단위(초당 5번), 적·투사체·쿨다운은 1/60초 고정 간격으로 나아간다. 한 고리에서 둘을 같이 돈다.
- 그리기는 지금 뱀처럼 칸 사이를 `alpha`로 잇는다. 타워 위치는 이어진 마디 자리를 쓴다 (사거리 계산도 같은 자리).

### 5.4 성능 목표

- 적 250마리, 마디 40개, 투사체 200개에서 중간급 휴대폰 60fps.
- 적·마디·투사체는 종류별 `InstancedMesh` 한 번씩 그린다. 판(41 × 41 = 1,681칸)은 인스턴스 한 번.
- 표적 찾기는 `spatialGrid`로 사거리 둘레 칸만 본다 (타워마다 모든 적을 훑지 않는다).

## 8. 개발 단계

단계마다 `npm test`, `npm run build`, 브라우저 확인을 마치고 다음 단계로 간다.

| 단계 | 할 일 | 끝난 기준 |
|---|---|---|
| 0. 공용 움직임 | `lib/gridSnake/`로 몸 움직임을 옮기고 지금 뱀이 그것을 쓰게 한다 | 지금 뱀의 테스트와 놀이가 그대로 |
| 1. 큰 판 | 새 게임 뼈대, 41 × 41 판, 따라가는 카메라, 울타리 피해·꺾기, 제 몸 지나가며 마디 잃기, 미니맵 | 판을 돌아다니고, 부딪히면 꼬리가 줄고 머리만 남으면 끝 |
| 2. 타워 상자 | 상자 생기기, 먹으면 꼬리에 타워 마디, 타워 모양 넷 | 네 타워가 모양으로 구분되고 몸에 쌓임 |
| 3. 적 | 적 넷, 파도, 머리 쪽 움직임, 몸 돌아가기, 서로 밀기, 머리 피해·무적 | 3분 동안 적이 늘어나고, 피하지 않으면 마디를 잃음 |
| 4. 자동 공격 | 표적 고르기, 투사체, 범위·느려짐·튀기, 처치 | 타워가 범위의 적을 쏘고 처치 수가 오름 |
| 5. 연출과 화면 | 맞음·터짐·피해 연출, 사거리 원, 점수 표, 시작 안내, `GAME OVER`, 멈추기 | 글 없이 상황이 읽힘 |
| 6. 기록과 메인 | 기록장, 왕관, 메인 페이지 컷과 미리 보기, 문서 | 다시 와도 기록이 남음 |
| 7. 맞추기 | 수치 조정, 휴대폰 성능 확인 | 처음 하는 사람이 2~4분 버팀, 휴대폰 60fps |

## 9. 테스트

DOM·GPU 없는 파일은 모두 단위 테스트한다. 난수는 씨앗을 받아 같은 판을 다시 만든다.

- **움직임 (`lib/gridSnake/`):** 지금 뱀 테스트를 옮김 + 마디 잃기, 제 몸 지나가기.
- **피해:** 적·제 몸·울타리 피해마다 꼬리 마디가 하나 줄고, 무적 1초 동안은 줄지 않고, 머리만 남았을 때 끝난다.
- **울타리:** 닿으면 오른쪽으로 꺾고 판 밖으로 나가지 않는다. 네 모서리에서는 왼쪽으로 꺾는다. 무적 동안에도 꺾는다. 받아 둔 방향이 울타리 쪽이면 버린다.
- **타워 상자:** 늘 3개, 뱀·다른 상자와 겹치지 않음, 먹으면 꼬리에 그 종류, 40마디에서 바꾸기.
- **타워:** 사거리 경계, 머리에 가장 가까운 적 고르기, 쿨다운, 범위 피해 범위, 느려짐 시간, 번개 튀는 수와 줄어드는 피해.
- **적:** 머리 쪽으로 다가감, 몸을 지나가지 않음, 생기는 자리가 판 안·화면 밖, 시간별 무리 크기와 종류, 최대 수.
- **기록:** 누적 계산과 저장된 값 검사 (뱀과 같은 방식).
- **성능:** 적 250마리, 마디 40개로 `step`을 600번 돌린 시간이 정해 둔 한도 안 (느린 기기 차이를 생각해 넉넉히).
