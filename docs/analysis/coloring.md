- **최신 여부 확인:** 아래 명령에 결과가 있으면 그 변경분만 확인해 이 문서를 고친다.

## 놀이 규칙

- 처음(2026-11-24)에는 2D 선 그림의 칸을 칠했고, 2026-11-25 사용자 요청으로 3D 도시로, 2026-11-28 사용자 요청으로 집 한 채와 그 안의 방으로 바꿨다 (넓은 도시는 집중하기 어려워서). 2D 구현은 커밋 `d6b0882`, 도시 구현은 커밋 `f925b71`의 `src/games/coloring/`(`city.ts`, `graphics/cityView.ts`)에 있다.
- 칠하는 단위는 메시 인스턴스 하나다. 가로등은 기둥과 머리, 사람은 몸과 머리, 나무는 줄기와 잎, 탁자는 상판과 다리처럼 나뉘어 따로 칠한다.
- **문:** 문을 칠하면 0.35초 뒤 1.2초 동안 바깥으로 열린다. 열리면 화면 아래 가운데에 노란 들어가기 버튼이 뜨고, 누르면 문을 지나 방 안으로 미끄러지듯 들어간다. 방 안에서는 나가기 버튼이 되고, 누르면 뒷걸음으로 문 밖 마당까지 빠져나와 집을 바라본다. 걸어서(키·휠·두 손가락) 드나들어도 된다. 문을 칠하기 전에는 닫힌 문이 길을 막는다.
- **방 안:** 바닥, 천장, 네 벽, 깔개, 탁자와 의자 둘, 소파와 쿠션 둘, 책장과 책, 스탠드(갓이 빛남), 화분, 액자와 그림, 시계를 칠한다.
- 색은 고르지 않는다. 판마다 8색 묶음을 새로 뽑고(`palette.ts`), 누를 때마다 그 묶음에서 고른다. 다시 누르면 다른 색이 되고, 같은 무리(탁자 상판과 다리 같은)의 다른 조각과 같은 색은 되도록 피한다.
- 칠하지 않은 물체는 종이색에 검은 테두리를 두른 색칠 공부 모습이다. 누르면 누른 자리에서 색이 둥글게 번진다.
- 모든 조각(바깥 31개, 방 안 23개, 모두 54개)을 칠하면 클리어: 화면 양쪽 아래 모서리에서 색종이가 터져 오르고, 오림 글자 `CLEAR!`가 뜨고, 다시 하기 버튼이 노랗게 흔들린다.
- 7초 동안 칠하지 않으면 안 칠한 조각이 노랗게 반짝인다.
- 하늘을 칠하면 그 색으로 지평선은 밝고 따뜻하게, 위로 갈수록 짙은 노을 그라데이션이 된다. 해를 칠하면 해가 그 색으로 빛나고, 물체를 비추는 빛과 하늘의 해 쪽 노을빛에도 그 색이 섞인다. 가로등 머리, 창, 스탠드 갓도 칠하면 음영 없이 빛난다.

## 조작

| 입력 | 동작 |
|---|---|
| 짧게 누르기 (8px 안, 0.6초 안) | 칠하기 |
| 끌기 (마우스, 한 손가락) | 둘러보기 |
| 두 손가락 벌리기·오므리기 | 앞뒤로 가기 |
| 두 손가락 끌기 | 옆·위아래로 가기 |
| 마우스 휠 | 앞뒤로 가기 |
| W A S D, 화살표 / E, Space / Q, Shift | 걷기 / 오르기 / 내리기 / 세 배 빠르게 |
| 일시 정지 버튼(오른쪽 위, 다시 하기 왼쪽), P, Esc | 일시 정지·재생 |
| 드나들기 버튼(아래 가운데, 문이 열린 뒤 문 앞이나 방 안에서만) | 집에 들어가기·나가기 |

일시 정지는 마당을 도는 사람의 움직임만 멈춘다 (2026-11-25 사용자 요청). 멈춘 동안에도 둘러보기, 움직이기, 칠하기는 그대로 되고, 칠하기 번짐·문 열림·힌트·색종이 연출도 계속 움직인다. 멈춘 동안 버튼은 노란 재생 삼각형이 된다. 새 판(다시 하기)을 해도 멈춤 상태는 그대로다.

카메라는 반지름 30m, 높이 1.2~18m 안에서만 움직인다 (`CAMERA_BOUNDS`). 건물 벽·지붕·닫힌 문은 카메라(반지름 0.35m)를 막고, 막히면 그 축으로만 멈춰 벽을 따라 미끄러진다. 한 번에 멀리 가는 움직임(휠, 두 손가락)은 벽을 건너뛰지 않게 0.2m씩 나눠 움직인다. 드나들기로 미끄러지는 동안에는 다른 이동과 둘러보기를 받지 않는다. 세로로 긴 화면에서는 가로 시야가 62도 아래로 좁아지지 않게 세로 시야를 최대 95도까지 넓힌다.

## 미니 게임 계층 (`src/games/`)

3D 행성 엔진(`engine/`)은 캐릭터 이동, 포인터 잠금, 시작·일시 정지 화면을 전제로 해서, 색칠 놀이는 엔진을 거치지 않고 three.js를 직접 쓰는 계층으로 따로 두었다.

```
?game=<id> ── main.ts ── import('./games') ── findGame(id).start(#play)
```

| 파일 | 내용 |
|---|---|
| `src/games/game.ts` | `GameDefinition { id, start(root) }`. 게임이 `root` 안에 화면을 만든다 |
| `src/games/index.ts` | `GAMES` 목록과 `findGame` |

- `main.ts`가 `?game=`을 먼저 보고, 맞는 게임이 없으면 `?scene=`·메인 페이지로 넘어간다. 게임 화면에서는 `<html>`에 `is-game`을 붙여 엔진의 캔버스·안내 화면을 숨기고 `#play`(index.html)를 쓴다.
- 게임 코드는 `import()`로 따로 청크가 된다. three.js 청크는 씬과 함께 쓴다.
- `src/layers.test.ts`가 검사한다: 게임은 `engine/`, `content/`, `home/`, 다른 게임을 가져오지 않고, `main.ts` 말고는 게임을 가져오지 않는다. three.js는 게임의 `graphics/`에서만 가져온다. 게임이 `lib/`을 가져오는 것은 된다.
- 메인 페이지 컷은 `"open": { "game": "<id>" }`로 게임을 연다 ([home.md](home.md)).

지금 게임: 색칠 놀이(`coloring`), 2048(`2048`, [game2048.md](game2048.md)), 뱀(`snake`, [snake.md](snake.md)), 룰렛 체스(`chess`, [chess.md](chess.md)), 타워 뱀(`tower-snake`, 개발 중, [towerSnake.md](towerSnake.md)).

새 게임 추가: `src/games/<게임>/index.ts`에 `GameDefinition`을 만들고 `GAMES`에 더한 뒤, `contents.json`의 `contents` 목록 끝에 `open.game`과 `added`로 항목을 더한다 (최근 콘텐츠가 첫 컷에 온다, [home.md](home.md)).

## 집 (`house.ts`)

좌표는 미터, y가 위, 건물 가운데가 원점이다. 문은 +z 쪽 벽 가운데에 있고, 해는 -z 쪽 지평선 조금 위(처음 시점에서 건물 오른쪽 뒤)다. 처음 시점은 `[0, 3, 19]`에서 건물(-z)을 본다.

- **건물:** 너비 10, 깊이 8, 벽 높이 4.6, 벽 두께 0.3. 앞벽에 너비 1.6, 높이 2.6 문 구멍이 있다. 겉벽은 상자 여섯 개를 합친 조각 하나(`facade`)다.
- **문:** 경첩이 문 구멍 왼쪽 끝에 있고, 문 조각은 경첩 그룹에 붙어 y축으로 돈다 (다 열리면 -1.7 라디안, 바깥으로). 열림 곡선 `doorOpenness(칠한 시각, 지금)`은 0.35초 기다린 뒤 1.2초 동안 0→1이다. 문 열림은 일시 정지와 상관없이 화면 시각(`HouseView.time`)으로 움직인다. 0.85 넘게 열리면 문틈이 뚫리고 드나들기 버튼이 뜬다. 문틀(문틀·문턱)은 칠하기 전에도 문 자리를 테두리로 보여 준다.
- **방:** 안쪽 반 너비 4.7, 반 깊이 3.7, 천장 4.4. 벽 안쪽 판은 겉벽 안쪽 면 바로 앞에 0.04m 판으로 붙여 겉벽과 따로 칠한다. 방 안 조각은 `inside: true`다.
- **바깥:** 하늘, 해, 땅(반지름 399 원판), 마당(반지름 13 원판), 앞길, 겉벽, 지붕, 문·문틀·차양, 간판, 창 둘과 창 화단·꽃, 가로등 둘(건물 앞 모서리 옆), 나무 둘, 벤치, 우체통, 마당을 반지름 11·11.6으로 도는 사람 둘.
- **조각 모양:** `PartGeometry`는 하늘·해·원판, 아니면 기본 도형(상자·원기둥·구·다면체·캡슐) 목록이다. 그리기 쪽이 기본 도형을 합쳐 메시 하나로 만든다.
- **칠할 조각 순서**(영역 번호 = 순서 + 1): 바깥 조각(하늘, 해, 땅, 마당, 앞길, 겉벽, 지붕, 문, 문틀, 차양, 간판, 창·화단·꽃·가로등 좌우, 나무, 벤치, 우체통, 사람) 다음 방 안 조각.
- **막는 벽:** `houseWalls(문이 열렸나)`는 벽 다섯 상자(앞벽은 문 양옆과 위), 지붕(천장 높이부터)과, 닫혔으면 문틈 상자를 돌려준다. `insideWall`은 상자를 카메라 반지름만큼 넓혀 검사한다.
- **드나드는 길(`DOORWAY`):** 들어갈 때는 지금 자리 → 문 앞 `[0, 1.7, 5.2]` → 방 안 `[0, 1.9, 2.9]`(조금 내려다봄). 나갈 때는 지금 자리 → 문 안쪽 `[0, 1.7, 2.7]` → 문 앞 → 마당 `[0, 2.6, 15]`. 둘 다 집 쪽(-z)을 본다. 들어가기 버튼은 건물 앞(z 4.2~22, |x| < 10)에서만 떠서 길이 벽을 지나지 않는다.

물체를 더하려면 `houseParts`의 바깥·방 안 목록에 조각(`name`, 기본 도형, 주인 자리, 무리)을 더한다. 움직이는 물체는 `PartOwner`에 주인 종류를 두고 `HouseView.update`에서 자리를 옮긴다.

## 그리기 (`HouseView`)

- 조각마다 메시 하나와 `ShaderMaterial`(GLSL3) 하나. 칠하면 그 재질의 uniform(새 색, 이전 색, 누른 자리, 시각, 번질 거리)만 바꾼다. 시각·힌트·빛은 모든 재질이 같은 uniform 객체를 나눠 쓴다.
- GLSL3를 직접 지정하면 three.js가 출력 변수를 선언하지 않으므로 프래그먼트 셰이더에서 `out vec4 fragColor`를 직접 선언한다.
- 번지기: 누른 자리를 메시 자체 좌표로 바꿔 두고, 0.5초 동안 그 자리에서 원이 커지며 새 색이 된다. 번질 거리는 누른 자리에서 경계 상자 꼭짓점까지 가장 먼 거리. 하늘은 방향 사이 각도로 0.9초 동안 번진다. 누른 자리 없이 칠하면(개발용) 하늘은 해 쪽, 나머지는 가운데에서 번진다.
- 음영: 빛은 해(역광)가 아니라 처음 시점의 왼쪽 위 앞에서 온다 (역광이면 칠한 색이 어둡게 묻혀서). 3단 툰(1.0, 0.88, 0.76)에 빛 색을 30% 섞는다.
- 테두리: `noOutline` 조각(하늘, 땅, 마당, 방 벽·바닥·천장)을 뺀 조각에 껍데기 메시를 자식으로 단다. 껍데기 지오메트리는 꼭짓점을 합쳐(`mergeVertices`) 부드러운 법선을 다시 계산한 것이라 상자 모서리에서도 끊기지 않는다.
- 하늘 구(반지름 420)는 `xyww`로 가장 먼 깊이에 그리고, 땅은 반지름 399 원판이다.
- 누르기: 화면 좌표에서 광선을 쏘아 칠할 메시들(테두리 제외) 가운데 가장 가까운 것을 고른다. 걷는 사람과 열리는 문도 그 순간의 자리로 맞는다. 밖에서는 겉벽이 방 안을 가리고, 문틈으로 보이는 방 안 물체는 밖에서도 칠할 수 있다.
- 색은 sRGB 값을 셰이더에서 그대로 쓴다. `MeshBasicMaterial`(색종이)은 `SRGBColorSpace`로 넣어 three.js가 변환한다.
- 색종이: 화면 위 정사영 장면에 `InstancedMesh` 180장. 장면을 그린 뒤 깊이만 지우고 겹쳐 그린다.

## 기록 (2026-11-25)

공용 기록장([saveRecords.md](saveRecords.md))에 `coloring`으로 남긴다.

- 칠할 때마다 하다 만 판(색 묶음, 조각마다의 색 번호, 누른 횟수, 논 시간, 시작 시각)을 저장하고, 화면이 가려지거나 페이지를 떠날 때도 저장한다. 다시 열면 같은 색 묶음과 칠한 그림으로 이어 한다. 칠해 둔 조각은 가운데에서 다시 번지며 나타난다. 카메라 자리와 일시 정지는 남기지 않는다.
- 문을 칠해 둔 판을 이어 하면 문은 곧바로 열린 채로 시작한다.
- 조각 수가 바뀌어(도시 → 집처럼) 저장한 색 번호 수가 맞지 않으면 이어 하지 않고 하다 만 판을 지운다. 기록장을 여는 동안 이미 칠하기 시작했으면 새 판을 그대로 둔다.
- 다 칠하면 클리어 판 기록을 쌓고 하다 만 판을 지운다. 도중에 다시 하기를 누르면 클리어하지 않은 판 기록을 쌓는다. 한 번도 칠하지 않은 판은 쌓지 않는다.
- 논 시간은 첫 칠하기부터 클리어까지 프레임 시간을 더한다. 화면이 가려지면 프레임이 멈춰 세지 않는다.
- 개발용: `__coloring.book()`.

## 메인 페이지 미리 보기

`src/home/previews/coloring.jpg`(900×900)는 개발 서버에서 화면을 900×900으로 맞추고 카메라를 `[-4.5, 3, 17.5]`, yaw -0.3, pitch -0.03에 두고 `__coloring.fillAll()`로 다 칠한 뒤(문이 열려 방 안이 보임) 색종이가 끝나고 캔버스를 JPEG(품질 0.85)로 저장했다 (2026-11-28). 저장은 브라우저에서 data URL을 로컬 일회용 수신 서버로 보내 파일로 썼다.

## 브라우저 확인 (2026-11-28, 개발 서버)

| 항목 | 결과 |
|---|---|
| 1024×768 처음 시점 | 종이색 집과 마당, 검은 테두리, 문틀로 드러난 문, 건물 오른쪽 뒤의 해, 걷는 사람 |
| 문 누르기 | 문이 칠해지고 바깥으로 열림, 들어가기 버튼이 뜸, 문틈으로 방 안이 보임 |
| 들어가기 버튼 | 문을 지나 방 안 `[0, 1.9, 2.9]`까지 미끄러짐, 탁자·의자·소파·책장·스탠드·액자가 보임, 버튼이 나가기로 바뀜 |
| 나가기 | 뒷걸음으로 마당 `[0, 2.6, 15]`까지 나와 집을 봄 |
| `__coloring.fillAll()` | 완성: 색종이, `CLEAR!`, 다시 하기 버튼 흔들림 |
| 콘솔 오류 | 없음 |

확인 환경의 프레임이 낮아 미끄러지기가 실제보다 느리게 보였다 (프레임 시간은 0.1초로 자른다).

확인하지 않은 것: 실제 터치 기기의 두 손가락 조작, 키보드로 걸어서 문 드나들기(테스트로 충돌만 확인), 이번 변경 뒤의 모바일 화면, WebGL2가 없는 브라우저(시작하지 못했다는 글만 뜬다).
