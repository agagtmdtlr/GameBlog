해 질 녘 3D 도시를 자유 시점으로 돌아다니며 물체(메시)를 누르면 그 판의 무작위 색이 채워지고, 모두 칠하면 완성되는 미니 게임(`src/games/coloring/`)의 구조와 수정 방법을 정리한 문서다.

- **최신 여부 확인:** 아래 명령에 결과가 있으면 그 변경분만 확인해 이 문서를 고친다.

## 놀이 규칙

- 처음(2026-11-24)에는 2D 선 그림의 칸을 칠했고, 2026-11-25 사용자 요청으로 3D 장면으로 바꿨다. 2D 구현은 커밋 `d6b0882`의 `src/games/coloring/`(`regions.ts`, `rasterize.ts`, `pictures/`)에 있다.
- 칠하는 단위는 메시 인스턴스 하나다. 차 한 대는 몸통과 지붕, 가로등은 기둥과 머리, 사람은 몸과 머리, 나무는 줄기와 잎으로 나뉘어 따로 칠한다. 차 바퀴, 건물 창, 도로 점선은 칠하지 않는다.
- 색은 고르지 않는다. 판마다 8색 묶음을 새로 뽑고(`palette.ts`), 누를 때마다 그 묶음에서 고른다. 다시 누르면 다른 색이 되고, 같은 무리(차 한 대 같은)의 다른 조각과 같은 색은 되도록 피한다.
- 칠하지 않은 물체는 종이색에 검은 테두리를 두른 색칠 공부 모습이다. 누르면 누른 자리에서 색이 둥글게 번진다.
- 모든 조각(71개)을 칠하면 클리어: 화면 양쪽 아래 모서리에서 색종이가 터져 오르고, 오림 글자 `CLEAR!`가 뜨고, 다시 하기 버튼이 노랗게 흔들린다.
- 7초 동안 칠하지 않으면 안 칠한 조각이 노랗게 반짝인다.
- 하늘을 칠하면 그 색으로 지평선은 밝고 따뜻하게, 위로 갈수록 짙은 노을 그라데이션이 된다. 해를 칠하면 해가 그 색으로 빛나고, 물체를 비추는 빛과 하늘의 해 쪽 노을빛에도 그 색이 섞인다. 가로등 머리도 칠하면 음영 없이 빛난다.

## 조작

| 입력 | 동작 |
|---|---|
| 짧게 누르기 (8px 안, 0.6초 안) | 칠하기 |
| 끌기 (마우스, 한 손가락) | 둘러보기 |
| 두 손가락 벌리기·오므리기 | 앞뒤로 가기 |
| 두 손가락 끌기 | 옆·위아래로 가기 |
| 마우스 휠 | 앞뒤로 가기 |
| W A S D, 화살표 / E, Space / Q, Shift | 걷기 / 오르기 / 내리기 / 세 배 빠르게 |
| 일시 정지 버튼(오른쪽 위, 다시 하기 왼쪽), P, Esc | 일시 정지·재생 |

일시 정지는 차와 사람의 움직임만 멈춘다 (2026-11-25 사용자 요청). 멈춘 동안에도 둘러보기, 움직이기, 칠하기는 그대로 되고, 칠하기 번짐·힌트·색종이 연출도 계속 움직인다. 멈춘 동안 버튼은 노란 재생 삼각형이 된다. 새 판(다시 하기)을 해도 멈춤 상태는 그대로다.

카메라는 반지름 140m, 높이 1.2~70m 안에서만 움직인다 (`CAMERA_BOUNDS`). 세로로 긴 화면에서는 가로 시야가 62도 아래로 좁아지지 않게 세로 시야를 최대 95도까지 넓힌다.

## 미니 게임 계층 (`src/games/`)

3D 행성 엔진(`engine/`)은 캐릭터 이동, 포인터 잠금, 시작·일시 정지 화면을 전제로 해서, 색칠 놀이는 엔진을 거치지 않고 three.js를 직접 쓰는 계층으로 따로 두었다.

```
?game=<id> ── main.ts ── import('./games') ── findGame(id).start(#play)
```

| 파일 | 내용 |
|---|---|
| `src/games/game.ts` | `GameDefinition { id, start(root) }`. 게임이 `root` 안에 화면을 만든다 |
| `src/games/index.ts` | `GAMES` 목록과 `findGame` |

- `main.ts`가 `?game=`을 먼저 보고, 맞는 게임이 없으면 `?scene=`·메인 페이지로 넘어간다. 게임 화면에서는 `<html>`에 `is-game`을 붙여 엔진의 캔버스·안내 화면을 숨기고 `#play`(index.html)를 쓴다.
- 게임 코드는 `import()`로 따로 청크가 된다. three.js 청크는 씬과 함께 쓴다.
- `src/layers.test.ts`가 검사한다: 게임은 `engine/`, `content/`, `home/`, 다른 게임을 가져오지 않고, `main.ts` 말고는 게임을 가져오지 않는다. three.js는 게임의 `graphics/`에서만 가져온다. 게임이 `lib/`을 가져오는 것은 된다.
- 메인 페이지 컷은 `"open": { "game": "<id>" }`로 게임을 연다 ([home.md](home.md)).

지금 게임: 색칠 놀이(`coloring`), 2048(`2048`, [game2048.md](game2048.md)), 뱀(`snake`, [snake.md](snake.md)), 체스(`chess`, [chess.md](chess.md)).

새 게임 추가: `src/games/<게임>/index.ts`에 `GameDefinition`을 만들고 `GAMES`에 더한 뒤, `contents.json`의 컷에 `open.game`을 넣는다.

## 도시 (`city.ts`)

좌표는 미터, y가 위, 해는 -z 쪽 지평선 조금 위다 (처음 시점에서 건물 사이로 보인다).

- **순환 도로:** 가운데 선이 반 너비 46, 반 깊이 22, 모서리 반지름 12인 둥근 직사각형. 도로 반 너비 4, 양쪽 인도 너비 3(높이 0.18). `loopPose(거리, 바깥쪽 거리)`는 가운데 선 기준 거리로 자리를 정하고 바깥쪽(나아가는 방향의 오른쪽)으로 옮긴다. 위에서 보면 반시계로 돈다. 그래서 같은 거리의 안쪽·바깥쪽 자리는 같은 단면에 있고, 도로·인도 띠를 같은 표본으로 만든다.
- **차 6대:** 바깥 차선(+2) 3대는 초속 9로 반시계, 안쪽 차선(-2) 3대는 초속 7.5로 시계 방향. 같은 차선 차는 빠르기가 같아 부딪치지 않는다 (테스트가 간격 8m 이상을 검사).
- **사람 10명:** 바깥·안쪽 인도를 각자 빠르기·방향·키로 걷고, 걸음마다 살짝 튄다.
- **가로등 8개:** 바깥 인도 바깥 가장자리에 고르게, 팔과 머리가 도로 쪽으로 뻗는다.
- **건물 8채**는 인도 바깥(테스트가 검사), **나무 4그루**는 안쪽 공원에 있다.
- **칠할 조각 순서**(영역 번호 = 순서 + 1): 하늘, 해, 땅, 공원, 도로, 바깥 인도, 안쪽 인도, 건물, 나무(줄기·잎), 가로등(기둥·머리), 차(몸통·지붕), 사람(몸·머리).

물체를 더하려면 `PartShape`에 종류를 더하고, `cityParts`에 조각을, `cityView.ts`의 `partGeometry`에 지오메트리를 더한다. 움직이는 물체는 `PartOwner`에 `car`·`person`처럼 주인을 두고 `CityView.update`에서 자리를 옮긴다.

## 그리기 (`CityView`)

- 조각마다 메시 하나와 `ShaderMaterial`(GLSL3) 하나. 칠하면 그 재질의 uniform(새 색, 이전 색, 누른 자리, 시각, 번질 거리)만 바꾼다. 시각·힌트·빛은 모든 재질이 같은 uniform 객체를 나눠 쓴다.
- GLSL3를 직접 지정하면 three.js가 출력 변수를 선언하지 않으므로 프래그먼트 셰이더에서 `out vec4 fragColor`를 직접 선언한다.
- 번지기: 누른 자리를 메시 자체 좌표로 바꿔 두고, 0.5초 동안 그 자리에서 원이 커지며 새 색이 된다. 번질 거리는 누른 자리에서 경계 상자 꼭짓점까지 가장 먼 거리. 하늘은 방향 사이 각도로 0.9초 동안 번진다. 누른 자리 없이 칠하면(개발용) 하늘은 해 쪽, 나머지는 가운데에서 번진다.
- 음영: 빛은 해(역광)가 아니라 처음 시점의 왼쪽 위 앞에서 온다 (역광이면 칠한 색이 어둡게 묻혀서). 3단 툰(1.0, 0.88, 0.76)에 빛 색을 30% 섞는다.
- 테두리: 하늘·땅·공원·도로를 뺀 조각에 껍데기 메시를 자식으로 단다. 껍데기 지오메트리는 꼭짓점을 합쳐(`mergeVertices`) 부드러운 법선을 다시 계산한 것이라 상자 모서리에서도 끊기지 않는다.
- 하늘 구(반지름 420)는 `xyww`로 가장 먼 깊이에 그리고, 땅은 반지름 399 원판이다.
- 누르기: 화면 좌표에서 광선을 쏘아 칠할 메시들(테두리 제외) 가운데 가장 가까운 것을 고른다. 움직이는 차·사람도 그 순간의 자리로 맞는다.
- 색은 sRGB 값을 셰이더에서 그대로 쓴다. `MeshBasicMaterial`(바퀴, 창, 점선, 색종이)은 `SRGBColorSpace`로 넣어 three.js가 변환한다.
- 색종이: 화면 위 정사영 장면에 `InstancedMesh` 180장. 장면을 그린 뒤 깊이만 지우고 겹쳐 그린다.

## 기록 (2026-11-25)

공용 기록장([saveRecords.md](saveRecords.md))에 `coloring`으로 남긴다.

- 칠할 때마다 하다 만 판(색 묶음, 조각마다의 색 번호, 누른 횟수, 논 시간, 시작 시각)을 저장하고, 화면이 가려지거나 페이지를 떠날 때도 저장한다. 다시 열면 같은 색 묶음과 칠한 그림으로 이어 한다. 칠해 둔 조각은 가운데에서 다시 번지며 나타난다. 카메라 자리와 일시 정지는 남기지 않는다.
- 도시 조각 수가 바뀌어 저장한 색 번호 수가 맞지 않으면 이어 하지 않고 하다 만 판을 지운다. 기록장을 여는 동안 이미 칠하기 시작했으면 새 판을 그대로 둔다.
- 다 칠하면 클리어 판 기록을 쌓고 하다 만 판을 지운다. 도중에 다시 하기를 누르면 클리어하지 않은 판 기록을 쌓는다. 한 번도 칠하지 않은 판은 쌓지 않는다.
- 논 시간은 첫 칠하기부터 클리어까지 프레임 시간을 더한다. 화면이 가려지면 프레임이 멈춰 세지 않는다.
- 개발용: `__coloring.book()`.
