# 몽환적인 땅과 지형물 구조 분석

행성 땅의 높낮이, 파스텔 색, 그 위에 흩어 놓은 둥근 지형물을 정리한 문서다.

- **규칙:** [rules/world.md](../rules/world.md)의 "행성 표면" 항목
- **색인:** [docs/README.md](../README.md)
- **분석 기준:** `feature/dreamy-terrain` 병합 커밋 (2026-11-22, 사용자가 보여 준 파스텔 숲 그림을 바탕으로 처음 만듦)

## 수정할 파일

| 하고 싶은 것 | 파일 |
|---|---|
| 언덕 수·크기·높이, 잔물결, 평평하게 둘 곳의 폭 | `game/terrain.ts`의 `TERRAIN_SHAPE` |
| 지형물 수·간격, 시드 | `game/terrain.ts`의 `PROP_LAYOUT` |
| 지형물 크기 범위와 충돌 캡슐 | `game/terrain.ts`의 `buildProp` |
| 지형물 색 | `game/terrain.ts`의 `DREAM_PALETTE` (sRGB 16진) |
| 언덕(`mound`)·기둥(`pillar`) 메시 단면 | `engine/dreamShape.ts` |
| 땅의 파스텔 물결, 지형물의 아래→위 색 변화, 가장자리 빛, 밤 빛 | `shaders/toon.frag`의 `PATTERN_DREAMY`, `PATTERN_GRADIENT` |
| 땅 메시의 정점 간격 | `engine/renderer.ts`의 `TERRAIN_DETAIL` |

## 땅의 높이

`terrainHeight(방향)`이 반지름 18에 더할 높이를 돌려준다. `TERRAIN`(`Ground`)이 그 함수를 가진 땅이다.

- **언덕:** 고정 시드로 고른 46개의 방향에 `amplitude * (1 - d²/w²)²` 꼴의 언덕을 더한다. 반지름 3~7.5, 높이는 반지름의 0.3배 이하이고 1.8 이하다. 18%는 절반 깊이의 움푹한 곳이다. 겹치면 2.2쯤까지 오른다.
- **잔물결:** 방향 좌표의 사인 곱 두 겹(높이 0.22, 0.11)을 더한다.
- **평평한 곳:** 선로(중심에서 2.0까지 0, 6.0에서 원래 높이), 시작 지점(3.0~7.0), 표면 객체(집·로켓, 바닥 대각선 절반 + 1.2에서 +4.0)는 높이에 0~1 가림을 곱한다. 그래서 선로·기차·집·로켓·시작 지점은 반지름 18의 구 위에 그대로 놓인다. 새 표면 객체를 장면 파일에 더하면 자동으로 평평해진다.
- **비탈:** 테스트가 50도보다 가파른 곳이 없는지 본다.

## 물리와 다리

- `physics/collision.ts`의 `Ground`는 `Sphere`에 선택적 `heightAt`을 더한 타입이다. 없으면 예전과 같은 구다. 테스트의 `PLANET`은 그대로 구로 쓴다.
- `sphereVsGround`는 구 아래 표면을 접평면으로 보고, 구가 평면에 닿는 높이(`반지름 / cos(기울기)`)까지 **위쪽(중심 바깥)으로** 밀어낸다. 법선도 위쪽이라 비탈에서 미끄러지지 않고 가만히 서 있다. 법선은 `groundNormal`이 중앙 차분으로 구한다.
- `Player.step`, `Walker`(발을 땅 높이에 놓음), `Wanderer`가 `TERRAIN`을 받는다. NPC 시작 높이도 땅 높이를 따른다. 위쪽과 중력은 여전히 행성 중심 방향이다.
- 카메라(`CameraRig`)에 땅을 주면 땅에서 0.8 아래로 내려가지 않는다. 지형물은 피하지 않는다.

## 지형물

`DREAM_PROPS`는 모듈을 불러올 때 한 번 만든다. 모양별 수는 언덕 9, 기둥 12, 공 12, 막대사탕 10, 장식 공 70이다.

| 모양 | 메시 | 크기 | 충돌 |
|---|---|---|---|
| `mound` 종 모양 언덕 | `mound` | 폭 3.6~6.2, 높이 2.6~5.2 | 반지름 폭×0.34인 세운 캡슐 |
| `pillar` 끝이 둥근 기둥 | `pillar` | 폭 1.2~2.3, 높이 3.4~7 | 기둥과 같은 캡슐 |
| `ball` 반쯤 묻힌 공 | `sphere` | 반지름 0.8~1.7 | 구 |
| `lollipop` 줄기 위의 공 | `cylinder` + `sphere` | 높이 3.8~5.4 | 줄기만 (공은 캐릭터 머리보다 높다) |
| `pebble` 작은 장식 공 | `sphere` | 반지름 0.18~0.45 | 없음, 그림자도 없음 |

- **배치:** 고정 시드로 방향을 뽑고, 평평한 곳의 안쪽 경계에서 바닥 반지름 + 1.0 안이면 버린다. 큰 지형물끼리는 바닥 반지름 합 + 2.4(걸어 지나갈 틈)를 띄운다. 바닥은 땅에 0.35 묻는다.
- **충돌:** `Capsule`(`a`, `b`, `radius`)이며 `World`가 집·로켓 상자와 함께 `obstacles`로 넘긴다. `Obstacle = OrientedBox | Capsule`이고 `sphereVsObstacle`이 나눠 부른다.
- **그리기:** 움직이지 않으므로 `World`가 그리기 항목을 한 번 만들어 둔다(`PROP_DRAW_ITEMS`). 그리기 목록에서 행성 땅 바로 뒤다. 재질은 `SurfacePattern.Gradient`이고 `emissive`는 0이다(해·전조등만 `emissive`가 있다는 테스트가 있다).

## 셰이더

- **`Dreamy` (땅):** 중심에서 본 방향의 사인 물결 세 겹으로 코사인 파스텔 팔레트(sRGB 0.4~1.0)를 골라 바탕색에 곱한다.
- **`Gradient` (지형물):** 오브젝트 공간 y로 아래는 보랏빛(`DREAM_SHADE`)으로 가라앉고 위는 15% 옅어진다.
- **공통:** 가장자리 빛(`(1 - N·V)³ × 0.18`)과 밤 빛(`night × 0.16`)을 바탕색으로 더해 밤 쪽에서도 은은하게 보인다.

## 렌더러

`Renderer.setTerrain(HeightField)`가 정이십면체 구(세분 72, 정점 약 5만 2천 개)를 높이 함수대로 밀어 월드 좌표 지오메트리를 만든다. `main.ts`가 `setTrack` 뒤에 부른다. 메시 종류는 `terrain`이고 단위 행렬로 그린다. 그림자를 드리우므로 언덕이 서로 그림자를 진다.

## 한계

- 다리와 발은 지형물을 모른다. 벽에 붙으면 발이 지형물에 묻힐 수 있다.
- 카메라는 지형물을 피하지 않아 큰 언덕 뒤에서는 가려질 수 있다.
- 땅 법선은 중앙 차분이라 매 물리 단계에 높이 함수를 몇 번 더 부른다. 높이 함수는 평평한 곳 약 70개와 언덕 46개를 돈다.
