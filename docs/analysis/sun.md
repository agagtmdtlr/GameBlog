# 해 분석

행성 둘레를 도는 해와, 해를 따라 움직이는 직사광의 구조다.

- **규칙:** 없음
- **색인:** [docs/README.md](../README.md)
- **분석 기준:** 커밋 `61671b7` 다음의 해 추가 (2026-11-21)

## 동작

- 해는 주황색으로 스스로 빛나는 구체다. 행성 중심에서 70 떨어진 궤도를 120초에 한 바퀴 돈다 (`SUN` in `game/sun.ts`).
- 직사광 방향(`Environment.lightDirection`)은 매 프레임 행성 중심에서 해를 향하는 단위 벡터다. 해 구체의 위치와 같은 값에서 나오므로 항상 맞는다.
- 시작할 때 해의 방향은 `STUDIO_ENVIRONMENT.lightDirection`(예전 고정 조명 방향)이다. 그래서 시작 화면은 해를 넣기 전과 같다.
- 궤도는 시작 방향과 시작 지점(+Y) 위를 지나는 대원이다. 시작하면 해가 시작 지점 머리 위로 떠올랐다가 반대편으로 지고, 한동안 밤이 된다.
- 해는 `World.fixedStep`에서만 움직인다. 시작 화면과 일시 정지 중에는 멈춘다.
- 밤에 따로 처리하는 것은 없다. 해가 행성 반대편에 있으면 표면의 `N·L`이 음수가 되고, 행성이 그림자 맵에 그려지므로 그림자도 진다. 앰비언트(하늘·땅 색)만 남는다.

## 파일

| 파일 | 내용 |
|---|---|
| `game/sun.ts` | `SUN` 상수, `SUN_EMISSIVE`, `Sun` 클래스(`step`, `direction(alpha)`, `position(alpha)`) |
| `game/world.ts` | `World.sun`을 `fixedStep`에서 진행하고, 그리기 목록 끝에 해 구체를 넣고, `environment(alpha)`로 해 방향을 담은 조명 환경을 만든다 |
| `main.ts` | 렌더러에 `STUDIO_ENVIRONMENT` 대신 `world.environment(alpha)`를 넘긴다 |
| `engine/renderer.ts` | 광원 방향이 +Y와 거의 나란하면 그림자 카메라의 위쪽을 +Z로 바꾼다 (`lookAt` 특이점) |

## 세부

- **보간:** `Sun`은 이전 각도와 지금 각도를 들고, 물리와 같은 `alpha`로 보간한다. 한 바퀴를 넘어 각도가 0으로 돌아가면 이전 각도에서 2π를 빼서 보간이 거꾸로 돌지 않게 한다.
- **재질:** 기본색 검정, `SUN_EMISSIVE` = [1.2, 0.18, 0.01]. 셰이더의 ACES 톤 매핑이 밝은 발광을 눌러 노랗게 만들므로 세기를 1 가까이로 둔다. 3 정도로 올리면 노란색으로 보인다.
- **그림자:** 해는 `castShadow: false`라 그림자 레이어에 들어가지 않는다. 그림자 카메라는 광원 방향으로 48(`shadowRadius * 2`) 떨어져 원점을 보므로 해 구체(70)는 범위 밖이다.
- **시차:** 궤도 반지름이 행성(18)에 비해 크지 않아, 캐릭터 시점에서 보이는 해의 높이는 직사광의 높이보다 조금 낮다. 해가 낮게 뜨면 직사광은 아직 비추는데 해는 지평선 아래로 보일 수 있다.
