# 플레이어 캐릭터 구조 분석

구체 몸과 절차적으로 움직이는 두 다리로 된 플레이어 캐릭터의 구조다. 다리는 엉덩이에서 발끝까지 하나로 이어진 스킨 메시다.

- **규칙:** [rules/character.md](../rules/character.md)
- **색인:** [docs/README.md](../README.md)
- **분석 기준:** 커밋 `40def49` 다음의 구를 캐릭터로 교체
- **최신 여부 확인:** 아래 명령에 결과가 있으면 그 변경분만 확인해 이 문서를 고친다.

```bash
git log --oneline 40def49..HEAD -- tools/blender src/assets src/game/walker.ts src/game/player.ts src/game/world.ts src/engine/renderer.ts src/engine/skinning.ts
```

## 흐름

| 단계 | 파일 | 하는 일 |
|---|---|---|
| 모델링 | `tools/blender/build_character.py` | Blender 스크립트로 다리 스킨 메시 `Leg`와 뼈 `Thigh`, `Shin`, `Foot`을 만들어 `src/assets/character.glb`로 내보낸다 |
| 물리 | `game/player.ts` | 반지름 0.88의 보이지 않는 충돌 구. 중심이 몸의 중심이고, 반지름이 다리가 몸을 받치는 높이다. 굴러가는 회전은 계산하지 않는다 |
| 걸음 | `game/walker.ts` | 물리 결과(위치, 속도, 접지)를 보고 몸의 방향과 두 발의 위치를 정한다. 그릴 때 두 마디 IK로 무릎을 풀어 다리마다 뼈 3개의 위치와 축을 낸다 |
| 그리기 목록 | `game/world.ts` | 몸(`sphere`)과 다리마다 `leg` 항목 하나를 만든다. 순서는 행성, 몸, 왼다리, 오른다리다. 다리 항목의 `skin`은 뼈마다 `지금 뼈 × 기본 자세 뼈의 역행렬`이다 |
| 스키닝 | `engine/skinning.ts` | 정점마다 뼈 행렬을 가중치로 섞는 선형 블렌드 스키닝 (CPU) |
| 렌더러 | `engine/renderer.ts` | `loadCharacter(url)`가 glb를 `GLTFLoader`로 불러와 기본 자세 정점과 뼈 번호·가중치를 꺼낸다. 풀의 메시마다 다리 지오메트리 복사본을 두고 매 프레임 스키닝 결과를 쓴다. 불러오기 전에는 몸만 보인다 |

## Blender 다리 메시 규약

오른쪽 다리가 서 있는 기본 자세 하나로 만들고, 게임은 왼쪽 다리에도 같은 메시를 쓴다. 뼈 행렬이 회전과 이동뿐이라 왼쪽 다리는 메시를 뒤집지 않고 돌려서 놓는다. 좌표는 glTF(+Y 위) 기준이며, 스크립트에서는 glTF (x, y, z)를 Blender (x, -z, y)로 옮겨 모델링한다.

| 항목 | 값 |
|---|---|
| 원점 | 엉덩이 관절. +X가 몸 바깥, +Y가 위이고 다리는 Z = 0 평면에 놓인다 |
| 무릎, 발목 | `(0.6, 0.5)`, `(0.62, -0.81)`. 허벅지 0.781, 정강이 1.31. 무릎이 엉덩이보다 0.5 높아 몸 꼭대기와 비슷한 높이로 솟는다 (2026-11-21 사용자 요청으로 0.25에서 올림). 정강이는 거의 수직이다 |
| 발 | 발바닥이 발목에서 0.12 아래, 발끝은 +X |
| 뼈 | `Thigh`(엉덩이→무릎), `Shin`(무릎→발목), `Foot`(발목→발끝) |

- 기본 자세는 `walker.ts`의 `LEG_REST`, `LEG`와 같아야 한다. `walker.test.ts`가 스크립트의 `REST_KNEE`, `REST_ANKLE`, `ANKLE_HEIGHT`를 읽어 비교한다.
- 기본 자세는 서 있을 때 IK가 푸는 자세와 같게 골랐다 (몸 높이 0.88, 엉덩이 옆 0.45·위 0.05, 발 옆 1.07). 자주 쓰는 자세에 가까울수록 스키닝 변형이 작다.
- 메시는 점 7개를 잇는 스킨 모디파이어 관에 서브디비전을 적용해 만든다. 엉덩이 안쪽으로 0.14 더 뻗어 몸 구 안에서 시작하고, 발은 발바닥 아래 정점을 평평하게 깎는다.
- 가중치는 정점에서 뼈 선분까지 거리의 역수 6제곱을 정규화하고 0.01 미만은 버린다. 무릎과 발목 부근이 두 뼈 사이에서 부드럽게 섞인다.
- 게임은 내보낸 뼈의 변환과 역바인드 행렬을 쓰지 않는다. 뼈 번호는 이름으로 [Thigh, Shin, Foot] 순서에 맞춘다.
- 내보내는 속성은 `POSITION`, `NORMAL`, `JOINTS_0`, `WEIGHTS_0`이다. 색과 거칠기는 `World`의 `PLAYER_COLOR`, `PLAYER_ROUGHNESS`로 준다.

다시 만드는 명령:

```bash
"C:/Program Files/Blender Foundation/Blender 5.2/blender.exe" --background --factory-startup --python tools/blender/build_character.py
```

`-- --save-blend`를 붙이면 `tools/blender/character.blend`도 저장한다. 원본은 스크립트이므로 Blender에서 직접 고친 내용은 스크립트에 옮겨야 남는다.

## 걸음 (`Walker`)

고정 간격(120Hz)으로 `World.fixedStep`에서 `Player.step` 다음에 호출된다. three.js에 의존하지 않는다.

- **방향:** 수평 속도가 0.4보다 빠르면 진행 방향으로 몸을 돌린다(지수 감쇠, 비율 12). 위쪽은 `normalize(몸 위치 - 행성 중심)`이다.
- **쉬는 발 위치:** 몸 아래 표면에서 오른쪽 축으로 ±1.07.
- **내딛기:** 목표 = 쉬는 위치 + 수평 속도 × 걸음 시간. 발이 목표에서 0.22(멈춘 뒤에는 0.05) 넘게 벗어나면 내딛는다. 더 많이 벗어난 발부터 고르고, 다른 발이 내딛는 중이면 2.5배 벗어날 때까지 기다린다.
- **걸음 시간:** `0.5 / 속도`를 0.07~0.16초로 자른다. 빠를수록 잰걸음이 된다. 걸음 중에는 smoothstep으로 표면을 따라 옮기고 `0.28 × sin(π t)`만큼 든다. 목표가 움직이면 착지점도 따라간다.
- **몸 흔들림:** 발을 드는 동안 몸을 최대 0.04 올린다.
- **공중:** 0.12초 넘게 땅에서 떨어지면 발을 몸 아래로 매단다. 착지하면 걸음 중간(진행도 0.5)에서 이어받아 땅으로 내린다.
- **보간:** 몸, 방향, 발의 이전 값과 현재 값을 들고 있어 `pose(alpha)`가 보간한다. IK는 그릴 때마다 푼다.

## 다리 IK (`solveLegs`, `solveTwoBone`)

- 엉덩이 = 몸 중심 + 오른쪽 × ±0.45 + 위 × 0.05. 다리 메시가 몸 구(반지름 0.5) 안에서 시작해 이음매가 보이지 않는다.
- 발목 목표 = 발바닥 + 발 위치의 위쪽 × 0.12.
- 무릎은 `옆 + 위 × 2.0` 방향(pole)으로 굽어 컨셉처럼 바깥 위로 솟는다. 닿지 않는 목표면 다리를 곧게 편다.
- 허벅지와 정강이 뼈는 원점이 관절, +Y가 뻗는 방향, +Z가 pole 쪽이다. 발 뼈는 발 위치의 위쪽을 Y로, 진행 방향에서 바깥으로 75° 돌린 방향을 발끝(Z)으로 놓는다.
- `restBones()`가 같은 규약으로 기본 자세의 뼈를 만든다. 규약이 같아야 스키닝 행렬이 기본 자세에서 단위 행렬이 된다.

## 렌더링에서 바뀐 점

- `Material.receivesOccluder`가 켜진 메시(행성)만 몸이 만드는 앰비언트 오클루전을 받는다. 예전에는 구 줄무늬 무늬(`SphereBands`)로 플레이어를 구분했으나 무늬와 함께 지웠다.
- 몸 구는 회전하지 않는다. 생김새가 대칭이라 방향은 다리로만 보인다.
- 스키닝은 CPU에서 한다. 정점이 674개뿐이고, 셰이더와 그림자 패스(`overrideMaterial`)를 그대로 쓸 수 있다. 스키닝한 정점은 월드 좌표라 다리 항목의 `model`은 단위 행렬이고 화면 밖 제외(`frustumCulled`)를 끈다.
- 개발 서버에서 의존성 최적화 중에 three.js가 두 번 불러와질 수 있어, 불러온 메시는 `instanceof` 대신 `isSkinnedMesh`로 확인한다.

## 테스트

`game/walker.test.ts`: IK가 마디 길이를 지키고 pole 쪽으로 굽는지, 서 있을 때 발이 양옆 땅에 있는지, 걸을 때 발을 번갈아 내딛고 발목이 발바닥 위에 붙어 있는지, 진행 방향으로 도는지, 멈추면 발을 모으는지, 공중과 착지를 확인한다. 기본 자세가 Blender 스크립트와 같은지, 이웃한 뼈의 스키닝 행렬이 관절을 같은 곳으로 옮기는지, CPU 스키닝이 가중치대로 섞는지도 확인한다.

## 남은 일

- 발이 땅에 닿을 때의 기울기(발끝 들기)와 몸의 기울어짐이 없다.
- 선형 블렌드 스키닝이라 무릎을 기본 자세보다 많이 접으면 안쪽이 조금 눌린다.
- 행성 외의 지형이 없어 발 위치는 행성 표면에 투영만 한다.
