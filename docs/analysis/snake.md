## 놀이 규칙 (2026-11-28 사용자 요청 "스네이크 게임을 추가")

- 15 × 15 판. 뱀은 길이 3으로 가운데 줄에서 오른쪽을 보고 기다린다. 화살표 키·WASD나 끌기로 방향을 주면 나아가기 시작한다.
- 열매를 먹으면 한 마디 길어지고 점수가 1 오르며 조금 빨라진다 (초당 6.5칸에서 먹이마다 0.15칸, 최대 13칸). 새 열매는 뱀이 없는 칸 가운데 무작위로 생긴다.
- 벽(판 밖)이나 제 몸에 부딪히면 끝난다. 먹지 않는 칸에서는 꼬리가 같은 때 빠지므로, 지금 꼬리 칸으로는 들어갈 수 있다.
- 바로 반대 방향은 무시한다. 방향 바꾸기는 두 번까지 미리 받아 둬서 빠르게 두 번 꺾어도 놓치지 않는다.
- 판을 모두 채우면 오림 글자 `PERFECT!`, 부딪히면 `GAME OVER`가 뜨고 다시 하기 버튼이 노랗게 흔들린다.
- Space·Enter·P·Esc로 멈추고 이어 한다 (끝난 판에서는 Space·Enter가 다시 하기). 다른 탭이나 창으로 가면 저절로 멈춘다.
- 화면의 글은 점수 숫자와 끝났을 때의 오림 글자뿐이다. 버튼(메인으로, 멈추기, 처음부터)과 점수 표(열매: 먹은 수, 왕관: 가장 많이 먹은 수), 시작 안내(화살표 키 그림), 멈춤 표시(재생 삼각형)는 그림이다.

## 공용 움직임 (`src/lib/gridSnake/`, 2026-11-28)

몸 움직임은 뱀과 타워 뱀([plans/towerSnake.md](../plans/towerSnake.md))이 함께 쓰도록 `lib/gridSnake/`로 옮겼다 (게임끼리는 서로 가져올 수 없어서). 부딪힘은 판정만 돌려주고, 그 결과(끝, 피해, 꺾기)는 게임이 정한다.

| `GridSnake` | 하는 일 |
|---|---|
| `place(body, direction)` | 몸과 방향을 놓고 받아 둔 방향을 비운다 |
| `turn(direction)` | 방향을 받아 둔다. 마지막으로 받은 방향과 같거나 반대면 무시, `queueLimit`(기본 2)까지 |
| `takeDirection()`, `clearQueue()` | 받아 둔 방향 하나를 꺼내 지금 방향으로 / 모두 버림 |
| `ahead(direction, from)`, `inside(cell)` | 한 칸 앞 칸 / 판 안인지 |
| `bodyHit(cell, grow)` | 머리가 그 칸으로 가면 부딪히는 마디 번호(없으면 -1). 늘지 않으면 꼬리 칸은 비어 있는 것으로 본다 |
| `moveTo(cell, grow)` | 머리를 옮기고, 늘지 않으면 꼬리를 뺀다. 부딪힘은 보지 않으므로 제 몸을 지나가는 규칙도 만들 수 있다 |
| `shrink(count)` | 꼬리 끝부터 마디를 잃는다. 머리는 남긴다 |
| `occupies`, `freeCells`, `cellAt` | 몸이 있는 칸, 빈 칸 번호 목록, 번호 → 칸 |
| `RIGHT_OF`, `LEFT_OF`, `OPPOSITE` | 나아가는 쪽에서 오른쪽·왼쪽·반대 방향 |

`SnakeGame.tick`은 `takeDirection` → `ahead` → `inside`(아니면 `wall`로 끝) → `bodyHit`(있으면 `self`로 끝) → `moveTo` 순서다. 테스트는 `src/lib/gridSnake/gridSnake.test.ts`에 있고, 뱀 테스트(`snake.test.ts`)는 옮기기 전과 같다.

## 시간과 움직임

- `index.ts`의 `requestAnimationFrame` 고리가 흐른 시간을 모으고, `1 / speed`초마다 `tick`한다. 한 장면에서 따라잡는 시간은 0.1초까지다.
- 그리기는 칸 사이를 매끄럽게 잇는다. `SnakeView.step(before, after, …)`이 마디마다 옛 자리(`from`)와 새 자리(`to`)를 남기고, `render`가 이번 칸으로 나아간 정도(`alpha`)로 섞는다. 늘어난 꼬리 마디는 옛 꼬리 자리에 그대로 있다.
- 몸은 마디 사이에 공을 두 개씩 더 넣어 이어 보이게 하고, 꼬리 쪽으로 가늘어진다(반지름 0.4 → 0.24). 세 마디마다 노란 띠다. 먹은 열매는 혹(반지름 22%)이 되어 머리에서 꼬리로 내려간다.
- 머리는 첫 두 마디 사이의 방향을 보고, 혀를 날름거린다.

## 카메라

- 시야 38도, 판을 58도 높이에서 내려다본다. `resize`가 판 둘레의 여덟 꼭짓점이 화면의 90% 안에 들도록 가장 가까운 거리를 이분 탐색으로 찾는다.
- 위 버튼 줄(64px) 아래 영역의 가운데에 판이 오게 `setViewOffset`으로 화면을 위로 늘린다. 캔버스는 화면 전체를 덮는다.
- 천천히 조금 흔들리고, 부딪히면 0.45초 떨린다.
- 색은 sRGB 값을 셰이더에 그대로 넣고 그대로 낸다 (색칠 놀이와 같은 방식). 그림자 원만 `MeshBasicMaterial`이라 `SRGBColorSpace`로 넣는다.

## 기록 (2026-11-28)

공용 기록장([saveRecords.md](saveRecords.md))에 `snake`로 남긴다.

- 부딪히거나(`wall`·`self`) 판을 채우면(`full`), 또는 도중에 처음부터 버튼을 누르면(`restart`) 판 기록을 쌓는다. 한 칸도 나아가지 않은 판은 쌓지 않는다.
- 실시간 놀이라 하다 만 판은 남기지 않는다. 다시 열면 새 판이다.
- 왕관 점수는 누적 수치의 `best`와 지금 점수 가운데 큰 값이다.
- 기록장을 여는 동안에도 놀 수 있고, 그동안 끝난 판은 쌓이지 않는다.
- 개발용: `__snake.stats`, `__snake.book()`, `__snake.load(body, direction, food)`, `__snake.gl.getError()`.

## 메인 페이지

- 메인 페이지 콘텐츠 목록에 넣었다 (`contents.json`, `open.game: "snake"`). 놓이는 컷은 더한 날 순서로 정해진다 ([home.md](home.md)의 "지금 놓인 순서"). 처음 넣을 때는 컷 `c`였다.
- 미리 보기 `src/home/previews/snake.jpg`(900×530)는 개발 서버를 1100×760으로 열고 `__snake.load`로 S자로 감긴 길이 19의 뱀과 머리 앞 열매를 놓은 뒤, 캔버스 가운데를 컷 비율(약 1.7)로 잘라 JPEG로 저장했다. 저장은 브라우저에서 data URL을 로컬 일회용 수신 서버로 보내 파일로 썼다.
