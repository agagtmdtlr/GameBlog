# NPC 구조 분석

행성 위를 혼자 돌아다니는 NPC들의 구조다. 모양과 걸음은 플레이어 캐릭터와 같고 마리마다 색만 다르다.

- **규칙:** 없음. 모양과 걸음은 [rules/character.md](../rules/character.md)를 따른다
- **색인:** [docs/README.md](../README.md)
- **분석 기준:** 커밋 `649f5c7` 위의 `feature/wandering-npc` (2026-11-21, 처음 추가), `feature/more-npcs`에서 5마리로 늘림
- **최신 여부 확인:** 아래 명령에 결과가 있으면 그 변경분만 확인해 이 문서를 고친다.

```bash
git log --oneline 649f5c7..HEAD -- src/game/npc.ts src/game/npc.test.ts src/game/world.ts
```

## 흐름

| 단계 | 파일 | 하는 일 |
|---|---|---|
| 행동 | `game/npc.ts`의 `Wanderer` | 쉬기와 걷기를 되풀이한다. 쉬는 시간이 끝나면 지금 위치에서 아무 방향으로 표면 거리 6~13.5(4~9 × `CHARACTER_SCALE`) 떨어진 목표를 고른다 |
| 물리 | `game/player.ts`의 `Player` | 플레이어와 같은 몸체. 입력 대신 목표 쪽 접선 방향 × `WANDER_EFFORT`(0.32)를 받아 최고 속도가 약 3.4다(플레이어 약 10.6). 집·로켓 자리 상자와 충돌한다 |
| 걸음 | `game/walker.ts`의 `Walker` | 플레이어와 같은 클래스. 물리 결과로 서기·걷기 클립과 발을 정한다 |
| 밀어내기 | `game/npc.ts`의 `separateBodies` | 두 캐릭터 몸체가 겹치면 반씩 밀어내고 다가가는 속도를 없앤다. 튕기지 않는다. 월드는 플레이어와 모든 NPC의 모든 쌍에 한 번씩 부른다 |
| 월드 | `game/world.ts` | 목록 `NPCS`(시작 위치, 색)로 `World.npcs`를 만든다. `fixedStep`에서 플레이어 이동 → NPC마다 `move` → 모든 쌍 `separateBodies` → 플레이어 `walker.step` → NPC마다 `animate` 순서다. 그리기 목록에서 플레이어 몸·다리 다음에 NPC마다 몸·다리를 제 색으로 넣는다 |

## 값

| 항목 | 값 |
|---|---|
| 목록 `NPCS` | 5마리. 위도·경도와 색(sRGB): (74, 145) 하늘색 #4FB0F0, (45, 70) 분홍 #F0709C, (10, 290) 초록 #6CCB5F, (-25, 10) 보라 #A57CE8, (-60, 200) 주황 #F08A3C. 첫째만 시작할 때 보이는 집 자리 옆이고 나머지는 행성 둘레에 흩어 있다. 로켓 자리는 위도 30, 경도 207.5 |
| 거칠기 | 플레이어와 같은 `PLAYER_ROUGHNESS` |
| 쉬는 시간 | 1.2~3.5초. 도착하거나 한 목표를 12초 넘게 걸으면 쉰다 |
| 도착 | 목표까지 표면 거리 0.9 이내 |
| 막힘 | 걷기 시작 0.8초 뒤부터 수평 속도가 0.6보다 느린 상태가 0.8초 이어지면 0.6~1.2초 쉬고 다른 목표를 고른다 (벽, 플레이어에 막힘) |

- 난수는 `World` 생성자의 세 번째 인자(`Random`)로 바꿀 수 있다. 기본은 `Math.random`이고, 테스트는 `seededRandom(시드)`로 같은 길을 재현한다.
- NPC는 작동 영역을 켜지 않고, 해의 눈과 앰비언트 오클루전(`occluder`)은 플레이어만 따른다.

## NPC 추가·변경

- 수, 색, 시작 위치: `world.ts`의 `NPCS`에 `npcAt(위도, 경도, 선형 RGB)` 줄을 더하거나 뺀다. `npc.test.ts`가 시작 위치가 장애물·플레이어·서로와 겹치지 않는지(서로 간격은 충돌 구 반지름의 4배 넘게), 색이 모두 다른지 확인한다.
- 걷는 빠르기, 거리, 쉬는 시간: `npc.ts` 맨 위 상수. 거리 값은 `CHARACTER_SCALE`을 곱한다.
- 비용: 다리 스키닝은 CPU라 마리마다 매 프레임 정점 674개 × 2를 더 계산하고, 그리기 항목이 3개씩 는다. 밀어내기는 모든 쌍이라 수의 제곱으로 는다. 수십 마리 넘게 늘리려면 둘 다 다시 봐야 한다.

## 테스트

`game/npc.test.ts`: 시작 위치가 장애물·플레이어·서로와 겹치지 않고 색이 다른지, 40초 동안 목표를 여러 번 고르며 표면을 벗어나거나 상자를 뚫지 않고 산책 속도로 걷는지, 도착하면 숨쉬기 자세로 돌아가는지, 같은 시드면 같은 길인지 확인한다. 밀어내기가 겹침과 다가가는 속도를 없애는지, 월드에서 플레이어가 NPC를 통과하지 못하는지, 1분 동안 NPC끼리 서로 통과하지 않는지, 그리기 목록에 NPC마다 제 색의 몸 하나와 다리 둘이 더해지는지도 확인한다.
