# 잔디밭과 바람 구조 분석

행성 땅을 빽빽하게 덮은 잔디와, 그 잔디를 휘날리게 하는 바람을 정리한 문서다.

- **규칙:** [rules/world.md](../rules/world.md)의 "행성 표면", [rules/threejs.md](../rules/threejs.md)
- **색인:** [docs/README.md](../README.md)
- **분석 기준:** `feature/wind-grass` (2026-11-25, 커밋 `18f1158` 위에서 처음 만듦, 사용자 요청)

## 수정할 파일

| 하고 싶은 것 | 파일 |
|---|---|
| 잔디 밀도, 키·폭 범위, 긴 잎 비율, 잔디 없는 곳의 여유, 셀 크기, 시드 | `content/planet/objects/grass.ts`의 `GRASS_FIELD` |
| 바람 축이 도는 주기, 축의 기울기, 잔잔함·거셈 세기, 불었다 잦아드는 주기, 돌풍 띠 빠르기 | `content/planet/objects/wind.ts`의 `WIND` |
| 잎이 휘는 모양, 돌풍 띠의 모양, 떨림, 몸이 밀어내는 범위 | `content/planet/shaders/grass.vert` |
| 잎 색(밑동·끝), 파스텔 섞기, 돌풍 반짝임, 조명 단계 | `content/planet/shaders/grass.frag` |
| 잎 마디 수, 카메라에서 줄기 시작·사라지는 거리, 셀을 고르는 거리 | `content/planet/graphics/grassLayer.ts`의 `SEGMENTS`, `FADE`, `REACH` |
| 잔디를 미는 몸 (지금은 플레이어와 NPC) | `content/planet/world.ts`의 `grassPushers` |
| 잔디를 심지 않는 곳 (선로, 표면 객체) | `content/planet/objects/terrain.ts`의 `BARE_SPOTS` |

## 잔디밭 (`objects/grass.ts`)

- **수:** 제곱 단위당 64포기, 행성 전체 약 21만 4천 포기. 처음 부를 때(`grassField()`) 한 번 만들고, 브라우저에서 약 240ms 걸린다.
- **셀:** 행성을 위도 띠 19개로 나누고, 띠마다 둘레를 약 3 단위 칸으로 나눈 458개 셀. 셀 안에서는 z(위도의 사인)와 경도를 고르게 뽑아 면적이 고르게 퍼진다. 포기는 셀 순서대로 `blades`에 이어 담기고, 셀은 `start`, `count`, 가운데 방향, 모서리까지의 반지름을 갖는다.
- **포기 값 (`BLADE_STRIDE` = 7):** 뿌리 x, y, z(땅 높이 `terrainHeight`에서 0.06 묻음), 방향각, 높이, 폭, 고유값(0~1). 키는 0.3~0.72이고 7%는 0.85~1.2로 길다.
- **잔디 없는 곳:** 선로와 표면 객체(텔레비전·로켓)의 평평한 곳 안쪽 경계에서 0.6 안쪽까지는 없고, 거기서 2.0 동안 키가 자란다. 시작 지점은 평평해도 잔디가 있다. 지형물은 바닥 반지름의 0.92배 안에 없다 (장식 공 포함). 셀마다 가까운 것만 골라 검사한다.

## 바람 (`objects/wind.ts`)

- 바람은 행성을 축(`axis`) 둘레로 감돈다. 땅 한 자리의 바람 방향은 `axis × 위쪽`이고, 축 가까이(축과 행성이 만나는 두 곳)는 잔잔하다. 축은 거의 수평이며(위 성분 0.3) 150초에 한 바퀴 돌아 바람 방향이 천천히 바뀐다.
- 세기는 0.12~1이다. 21초, 34초 주기 사인 두 겹으로 불었다 잦아들기를 되풀이한다. 첫 화면에서 불고 있도록 시간을 5초에서 시작한다.
- 돌풍 띠의 위상(`gustPhase`)은 세기에 따라 초당 0.35~1.1 라디안씩 나아간다.
- `World.fixedStep`이 `Wind.step`을 부르므로 일시 정지 중에는 바람도 멈춘다. `World.windFrame(alpha)`가 두 단계 사이를 보간한다.

## 그리기 (`graphics/grassLayer.ts`, `shaders/grass.*`)

- 행성 씬의 `RenderLayer`다. 잎 하나(마디 4, 정점 9, 삼각형 7)를 `InstancedBufferGeometry`로 포기 수만큼 그린다. 비눗방울 층보다 먼저 등록해 투명한 방울이 잔디에 덮이지 않는다.
- **셀 고르기:** 프레임마다 카메라 방향에서 표면 거리 21 안에 걸친 셀을 고르고, 고른 셀이 바뀔 때만 그 셀들의 포기를 인스턴스 버퍼에 옮겨 담는다. 시작 지점에서 약 5만 포기를 그린다.
- **거리:** 카메라에서 12부터 19까지 잎이 줄어 땅으로 사라지고, 멀수록 70%까지 솎아 내며 남은 잎은 2.4배까지 넓힌다.
- **휘기:** 정점 셰이더가 잎을 곡률이 일정한 호로 휜다(길이는 그대로, 가장 크게 1.35 라디안). 휘는 양 = 바람 세기 × 0.38 + 돌풍 띠 × 0.85 + 잎마다 다른 빠르기의 떨림, 그리고 잎마다 조금씩 제멋대로 기운다.
- **돌풍 띠:** 바람 축 둘레 각도를 따라 나아가는 사인 물결 두 겹. 띠가 지나는 잎은 깊이 눕고 끝이 옅게 반짝여, 바람 물결이 땅을 훑는 것이 보인다.
- **밀어내기:** 플레이어와 NPC(최대 8)의 몸 중심을 받아, 몸 반지름의 1.25배 안의 잎을 바깥으로 눕히고 30% 어둡게 한다.
- **색과 빛:** 밑동 #4FAE6E에서 끝 #C9F2A6으로 가는 풀빛에 땅과 같은 파스텔 물결(`dreamPalette`)을 섞는다. 법선은 잎 면과 위쪽을 섞어 덤불처럼 빛을 받고, 툰 셰이더와 같은 빛 단계·달빛·밤 빛을 쓴다. 톤 매핑과 sRGB 변환은 셰이더 안에서 한다.

## 브라우저 확인 (2026-11-25, 개발 서버)

| 항목 | 결과 |
|---|---|
| 시작 화면에서 플레이 | 땅이 잔디로 덮이고, 선로·텔레비전 자리는 비어 있다 |
| 바람 시간을 센 구간(26초)으로 옮김 | 잎이 한쪽으로 눕고 1초 사이에 물결치며 움직인다 |
| 캐릭터 발 둘레 | 몸 아래 잎이 바깥으로 눕고 어둡다 |
| 프레임, `gl.getError()`, 콘솔 오류 | 60fps, 0, 없음 |

확인하지 않은 것: 모바일 성능, 밤 쪽의 잔디 모습, 실제 키보드로 걸어 다니며 잔디 가르기.

## 한계

- 층(`RenderLayer`)은 그림자 패스에 들어가지 않아, 잔디는 그림자를 받지도 드리우지도 않는다. 캐릭터 그림자가 잔디에 가려 덜 보인다. 대신 밀린 잎을 어둡게 한다.
- 하프톤 점을 칠하지 않는다 (층에 `uHalftoneCell`이 없다).
- 다리와 발은 잔디를 모른다. 잎이 발을 뚫고 올라오는 것은 몸 밀어내기로만 가린다.
- 뿌리는 높이 함수에 놓이고 땅 메시는 정점 사이를 곧게 잇으므로, 언덕 비탈에서 뿌리가 조금 묻히거나 뜰 수 있다 (0.06 묻어 둠).
- 잔디밭 생성(약 240ms)은 씬을 처음 열 때 메인 스레드에서 한다.
