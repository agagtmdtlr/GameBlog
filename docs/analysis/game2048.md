## 놀이 규칙 (2026-11-25 사용자 요청)

- 4 × 4 판. 화살표 키·WASD나 끌어서 밀면 모든 타일이 그쪽 끝으로 붙고, 같은 숫자가 이웃하면 하나로 합쳐져 두 배가 된다. 한 번 민 사이에 합쳐진 타일은 다시 합쳐지지 않고, 미는 쪽 끝부터 합친다.
- 움직임이 있었으면 빈 칸 하나에 2(10%는 4)가 생긴다. 움직임이 없으면 판이 그쪽으로 살짝 흔들린다.
- 점수는 합쳐진 타일 값의 합이다. 가장 높은 점수는 `localStorage`의 `gameblog.2048.best`에 남는다.
- 2048을 처음 만들면 오림 글자 `2048!`이 뜨고 판이 흔들린다. 누르거나 다시 밀면 닫히고 계속 할 수 있다.
- 더 밀 수 없으면 오림 글자 `GAME OVER`가 뜨고 다시 하기 버튼이 노랗게 흔들린다.
- 화면의 글은 타일 숫자, 점수 숫자, 이기거나 끝났을 때의 오림 글자뿐이다. 버튼(메인으로, 처음부터)과 점수 표(별: 점수, 왕관: 최고 점수)는 그림 아이콘이다.

## 파일

| 파일 | 내용 | DOM |
|---|---|---|
| `board.ts` | `Board`: 판 상태, 밀기(`slide`, `move`), 새 타일(`spawn`), 끝 검사(`canMove`), 점수, 이김(`won`). 타일마다 `id`가 있어 화면이 같은 타일을 따라간다 | 없음 |
| `tileStyle.ts` | 타일 값마다 종이 색, 글자 색, 글자 크기 비율. 2~2048은 따뜻한 색에서 차가운 색으로 돌고, 그 뒤는 남색 | 없음 |
| `index.ts` | `game2048`. DOM으로 판·타일·점수·버튼을 만들고, 키·끌기 입력, 애니메이션 순서, 크기 맞추기, 개발용 `window.__game2048` | DOM |
| `game2048.test.ts` | 밀기·합치기 순서, 새 타일, 끝, 이김, id, 색 검사 | |

three.js를 쓰지 않는다. 타일은 `div`이고 움직임은 CSS(`src/style.css`의 "2048" 부분)로 한다.

## 그리기와 애니메이션

- 판 크기: 위 버튼 줄(64px)을 빼고 남은 곳의 가장 큰 정사각형(여백 12px, 최대 620px). 칸 사이 틈은 칸의 12%다. `ResizeObserver`로 다시 맞춘다.
- 타일은 바깥 `div`(`.g2048-tile`)를 `transform: translate`로 칸에 놓고, 안쪽 `.g2048-face`가 색·숫자·기울기(`rotate`, id마다 -2.1~2.1도)·튀기(`scale`)를 맡는다. 미끄러짐은 바깥의 `transition` 0.11초(`SLIDE_MS`와 같게 둔다).
- 밀기 한 번: 합쳐질 두 타일은 합쳐진 자리로 미끄러진 뒤 지우고, 합쳐져 생긴 타일과 새 타일은 미끄러짐이 끝난 뒤 보인다(합친 타일은 커졌다 돌아오고, 새 타일은 0에서 커진다).
- 2048 이상 타일은 반짝인다.

## 메인 페이지

- 컷 `e`에 넣었다 (`contents.json`, `open.game: "2048"`).
- 미리 보기 `src/home/previews/2048.svg`는 같은 색·선 굵기로 그린 판 그림(900 × 900)이다. 타일 색을 바꾸면 이 그림의 색도 같이 바꾼다.

## 브라우저 확인 (2026-11-25, 개발 서버)

| 항목 | 결과 |
|---|---|
| 800×600 화살표 키 | 타일이 미끄러지고 합쳐지며, 점수와 `+N`이 뜬다 |
| `__game2048.load(...)` 뒤 합치기 | 2048 이상 판에서 `2048!`이 뜨고 판이 흔들림. 2~4096 타일 색이 모두 다름 |
| 더 밀 수 없는 판 | `GAME OVER`, 판이 흐려지고 다시 하기 버튼이 노랗게 흔들림 |
| 375×812 (모바일) 끌기 | 끈 방향으로 밀림. 판이 화면 너비에 맞음 |
| 메인 페이지 컷 `e` | 미리 보기 그림, 누르면 `?game=2048` |
| 콘솔 오류 | 없음 |

확인하지 않은 것: 실제 터치 기기, `localStorage`를 막은 브라우저.
