# 별 하늘 배경 분석

배경 우주를 큐브맵 텍스처 하나로 그리는 구조다. 별은 모델이 아니라 텍스처에 찍은 점이다.

- **규칙:** 없음 ([rules/threejs.md](../rules/threejs.md)의 three.js 가져오기 범위는 지킨다)
- **색인:** [docs/README.md](../README.md)
- **분석 기준:** 커밋 `f9cbb47` 다음의 별 하늘 추가 (2026-11-21)

## 동작

- 시작할 때 별 5,000개를 구 위에 고르게 뿌리고, 1024×1024 캔버스 여섯 장(큐브맵 면)에 그린다. 고정 씨앗이라 매번 같은 하늘이다.
- 밝기는 `random() ** 6`이라 어두운 별이 대부분이고 밝은 별은 드물다. 색은 흰색 위주에 푸른색·노란색이 섞인다.
- 큐브맵은 카메라 위치와 무관하게 방향만으로 읽으므로 무한히 먼 하늘이 된다. 해·행성과 달리 움직이지 않는다.
- 바탕색은 sRGB (2, 3, 8)이다. `Environment.background`(검정)는 지우기 색으로만 남고, 하늘이 화면을 덮으므로 보이지 않는다.

## 파일

| 파일 | 내용 |
|---|---|
| `engine/starfield.ts` | `STARFIELD` 상수, 별 생성(`generateStars`), 면 투영(`projectToFace`), 캔버스 그리기(`drawStarfieldFaces`). three.js를 가져오지 않는다 |
| `engine/renderer.ts` | 캔버스로 `CubeTexture`를 만들어 `skyScene.background`에 넣고, 메인 패스에서 장면보다 먼저 그린다 |
| `engine/starfield.test.ts` | 씨앗 재현성, 면 축 방향, WebGL 면 좌표 규약, 모서리 이음매 |

## 세부

- **면 좌표:** WebGL 큐브맵 규약(면 순서 +X, -X, +Y, -Y, +Z, -Z, 면마다 `sc`, `tc`, `ma`)을 따른다. 캔버스 위쪽 줄이 t = 0이고 `CubeTexture`는 `flipY = false`라 그대로 맞는다. three.js 배경 셰이더는 X를 뒤집어 읽지만 하늘 전체가 거울상이 될 뿐 이음매에는 영향이 없다.
- **이음매:** 별을 그 방향이 향하는 모든 면(주축 성분이 양수인 면)의 평면에 투영하고, 번짐 반지름만큼 면 밖까지 허용해 그린다. 이웃 면 평면으로의 투영은 공유 모서리에서 이어지므로 모서리에 걸친 별이 양쪽 면에 나뉘어 그려진다.
- **크기 보정:** 면 가장자리일수록 텍스처 한 칸이 차지하는 각이 작아진다. 반지름에 면 평면까지 거리의 1.5제곱을 곱해 화면에서 보이는 크기를 비슷하게 맞춘다.
- **그리기:** 별마다 원형 그라디언트(중심 → 반지름 → 옅은 번짐)를 `lighter` 합성으로 더한다. 번짐을 크게 하면 별보다 성운처럼 보이므로 밝은 별만 조금 번지게 했다.
- **렌더링:** `skyScene`은 메시 없이 `background`만 가진 장면이다. 그림자 패스에는 들어가지 않는다. 내장 배경 셰이더가 깊이를 쓰지 않으므로 메인 장면이 그 위에 그려진다. `renderer.autoClear = false`라 배경 렌더가 화면을 지우지 않는다.
- **색공간:** `colorSpace = SRGBColorSpace`. 내장 배경 재질은 three.js 출력 변환을 거치고 `toneMapping`은 꺼져 있으므로 캔버스 색이 그대로 나온다.
- **메모리:** 밉맵 없이 1024² × 4바이트 × 6면 ≈ 24MB. 배경은 대부분 확대되어 보이므로 밉맵을 만들지 않는다.
