# 비눗방울 띠 분석

행성을 소행성대처럼 감싸고 떠다니는 비눗방울의 구조다.

- **규칙:** 없음. three.js를 가져오는 파일 목록은 [rules/threejs.md](../rules/threejs.md)를 따른다
- **색인:** [docs/README.md](../README.md)
- **분석 기준:** 커밋 `17c9436` 위의 `feature/bubble-belt` (2026-11-22, 사용자 요청: 비눗방울 사진과 소행성대 사진을 참고로 줌)

## 동작

- 비눗방울 240개(`BUBBLE_BELT.count`)가 행성 중심에서 32~44 떨어진 띠 평면 위, 평면에서 ±4 높이 안에 흩어져 있다. 카메라가 오를 수 있는 높이(약 29)보다 바깥이고, 해 궤도(70)보다 안쪽이다.
- 띠 평면은 적도에서 조금 기울었다(`BUBBLE_BELT.axis`). 시작 화면의 지평선 위를 비스듬히 가로지르고, 위성은 띠 평면에서 약 15 떨어져 방울과 닿지 않는다.
- 크기는 거듭제곱 분포라 작은 방울이 훨씬 많다(반지름 0.18~2.2). 45%는 무리 14개 둘레에 모여 소행성대처럼 몰린 곳이 생긴다. 무리 안의 방울은 반지름 0.9 이하다.
- 방울은 띠 축을 중심으로 공전한다. 안쪽 가장자리에서 300초에 한 바퀴이고, 바깥일수록 거리^1.5에 비례해 느리다. 저마다 5~11초 주기로 띠 축 방향으로 0.25~0.9만큼 둥실거리고, 바깥쪽으로 조금 흔들리며, ±4% 부풀었다 줄어든다.
- 모양과 움직임은 고정 씨앗(`BUBBLE_BELT.seed`)으로 만들어 늘 같다. `World.fixedStep`에서만 시간이 흐르므로 시작 화면과 일시 정지 중에는 멈춘다.
- 충돌과 그림자가 없다.

## 파일

| 파일 | 내용 |
|---|---|
| `game/bubbleBelt.ts` | `BUBBLE_BELT` 상수, `beltBasis`(띠 평면 기저), `BubbleBelt` 클래스(`step`, `bubbles(alpha)`). 씨앗 난수는 `engine/starfield.ts`의 `createRandom`을 쓴다 |
| `game/world.ts` | `World.bubbles`를 `fixedStep`에서 진행하고, `buildBubbles(alpha)`로 프레임 값을 낸다 |
| `engine/frame.ts` | `BubbleFrame`(중심, 반지름, `swirl`)과 `FrameData.bubbles` |
| `engine/bubbleRenderer.ts` | `BubbleBatch`. 반지름 1인 `SphereGeometry(1, 40, 24)`의 `InstancedBufferGeometry`와 인스턴스 속성 `iCenter`, `iRadius`, `iSwirl` |
| `engine/renderer.ts` | `bubbleScene`을 빌보드 뒤에 그린다 |
| `shaders/bubble.vert`, `shaders/bubble.frag` | 방울 셰이더 |
| `main.ts` | `world.buildBubbles(alpha)`를 `FrameData.bubbles`로 넘긴다 |

## 그리기

- **혼합:** `AdditiveBlending`, `depthWrite: false`, 깊이 검사는 한다. 검은색이 투명이라 정렬이 필요 없고, 행성·위성 뒤의 방울은 가려진다. 깊이를 쓰지 않으므로 빌보드보다 먼저 그리면 뒤쪽 별이 방울을 덮는다. 그래서 메인 패스 맨 끝에 그린다.
- **양면:** `DoubleSide`로 안쪽 면도 그리되 0.45배로 어둡게 해서, 방울 너머 가장자리가 은은하게 비친다. 비친 창과 반짝임은 바깥 면에만 있다.
- **막:** `1 − N·V`의 세제곱 프레넬로 가운데는 거의 비고 가장자리가 밝다. 맨 바깥에 가는 띠가 한 번 더 빛난다. 색은 막 두께를 흉내 낸 `cos` 무지개이고, 두께는 `N·V`, 법선 방향의 물결, `swirl`(방울마다 천천히 흐름)로 바뀐다.
- **비친 창:** 시점 공간 법선의 xy를 극좌표로 보고, 왼쪽 위(각 2.25)에 푸른 창, 오른쪽 아래(각 −0.75)에 초록 창을 휘어진 띠로 칠한다. 화면 기준이라 모든 방울에서 같은 쪽에 보인다. 창 모서리에 네 갈래 반짝임 두 개가 있고, 해 방향의 날카로운 반사 하이라이트가 따로 있다.
- 출력은 툰 셰이더와 같은 ACES 톤 매핑과 sRGB 변환을 거친다. 하프톤 점은 없다.

## 테스트

- `game/bubbleBelt.test.ts`: 기저 직교, 씨앗 재현과 개수, 작은 방울이 많은 크기 분포, 2분 동안 카메라 높이·해 궤도·위성과 닿지 않음, 시간에 따라 모든 방울이 움직이고 멈추면 그대로임.
